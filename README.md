# FernFutures radars

The public mirror of the radar pages DIP writes (Demand Intelligence Platform, decision D82): one page per client × sector × country under `{client}/{KEY}/` (for example `lcl/C01-ES/`), `radar.json` beside each, the month's copies under `{client}/{KEY}/YYYY-MM/`, and the pictures under `assets/`. Written by the radar-feed job after each run; nothing here is edited by hand. Served by GitHub Pages at radar.fernfutures.com.
